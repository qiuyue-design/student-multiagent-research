# 学生科研项目：多Agent学术科研助手
> 人工智能专业在校学生课程与科研项目，用于辅助课程论文、深度学习实验、文献研读与代码开发。

## 项目背景
作为AI专业学生，日常科研与学习中面临：
- 万字级论文、完整课程资料无法一次性解析
- 文献梳理、实验设计、代码开发流程割裂
- 多轮长文本交互、代码分析消耗大量Token

因此搭建了本多Agent系统，依托长上下文大模型实现科研全流程自动化辅助。

## 核心架构
系统包含五大Agent，协同完成科研全流程：
1.  文献解析Agent：处理长文本论文与课程资料
2.  知识萃取Agent：提取核心观点与关键数据
3.  长链路推理规划Agent：设计实验与写作流程
4.  代码生成实验Agent：开发与调试深度学习代码
5.  总结复盘Agent：整理结果并生成报告

## 校内使用场景
目前已在本专业课程、AI社团内测使用，用于：
- 课程论文与毕业设计辅助
- 深度学习实验代码开发
- 专业文献综述批量整理

## 技术栈
- 核心模型：Xiaomi MiMo-v2.5
- 开发语言：Python
- 架构：自主搭建多Agent协作系统
